# phoenix — working rules

What a continuous thought in a COCONUT-style model encodes, tested causally on a
two-layer model trained from scratch on graph reachability. Code in `src/phoenix/`,
tests in `tests/`, figure and number scripts in `scripts/`, literature notes in
`lit/NOTES.md`, running notes in `NOTES.md`, result files in `results/`.

## Rules

1. Pilot on about 10 graphs first. Write the prediction in `NOTES.md`. Then run at n=100.
2. Before any prediction, ask what the task structure forces.
3. A threshold is allowed only if it names the claim it protects.
4. Sensitivity controls must be on-manifold.
5. Nothing is fixed the same day it is conceived.
6. Numbers in prose always point to a results file.
7. Plain English everywhere.
